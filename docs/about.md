### Report Issues

Please report any bugs or feature requests directly to our issue tracker on GitHub. We encourage issue templates!

- [Report a bug](https://github.com/Prakharprasun/ultimate-installer/issues/new)
- [Request a feature](https://github.com/Prakharprasun/ultimate-installer/issues)
- [View GitHub Discussions](https://github.com/Prakharprasun/ultimate-installer/discussions)

### Contributing 

As we are heavily bootstrapping right now, the best way to help is to dive straight into `src/` and look for the TODOs! All pull requests and feature forks are welcome.
